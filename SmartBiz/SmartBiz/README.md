# SmartBiz AI – Intelligent Business Analytics Dashboard for SMEs

An enterprise-grade, production-ready SaaS web application designed to help Small and Medium Enterprises (SMEs) analyze their business performance using interactive dashboards, automated file imports, and AI-powered insights from Google Gemini.

## Features
- **Premium SaaS Dashboard**: Stripe/Power BI inspired UI with glassmorphism, gradients, micro-interactions, and dark/light mode.
- **10+ Interactive Chart.js Visualizations**: Revenue trends, profit analysis, category breakdowns, and expense tracking.
- **AI Business Advisor**: Integrated Google Gemini API for automated 12-point business recommendations and risk analysis.
- **Data Import & Processing**: Drag-and-drop CSV and Excel (.xlsx) upload with automated Pandas parsing and SQLite ingestion.
- **Executive Reporting Suite**: Printable dashboards, PDF executive summary reports, and CSV exports.
- **Comprehensive SME Modules**: Full CRUD inventory management, customer segmentation (RFM), sales invoicing, and real-time notifications.

## Quickstart
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser at `http://127.0.0.1:5000`. The database will automatically initialize and seed with realistic sample data!
